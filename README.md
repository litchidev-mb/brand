# Litchi Dev — brand assets

Official logos and colours for **MB „Litchi Dev"**. Published so that partners,
registries, directories and press always have the right file and never have to
redraw the logo themselves.

**Company:** MB „Litchi Dev" · legal entity code 308095569 · Vilnius, Lithuania

## Which file to use

| File | Size | When |
|---|---|---|
| `litchidev-horizontal.png` | 2400×501, transparent | **Default.** Letterheads, invoices, documents |
| `litchidev-horizontal-white.png` | 2400×501, white background | When the system rejects transparency (otherwise the background turns black) |
| `litchidev-vertical.png` | 1600×1520, transparent | When there is more room vertically than horizontally |
| `litchidev-vertical-white.png` | 1600×1533, white background | Vertical variant where transparency is not accepted |
| `litchidev-vertical-cream.png` | 1600×1533, cream background | Same, on the brand background |
| `litchidev-vertical-square-white.png` | 1600×1600, white | Square fields (registries, directories) |
| `litchidev-vertical-square-cream.png` | 1600×1600, cream | Square, on the brand background |
| `litchidev-mark.png` | 1200×1188, transparent | Mark only, no wordmark — stamps, watermarks |
| `litchidev-mark-square-cream.png` | 1024×1024, cream background | Profile picture: LinkedIn, Facebook, GitHub |
| `litchidev-wordmark.png` | 2400×314, transparent | Wordmark only, no mark |

Every PNG has an `.svg` next to it — **vector, sharp at any size**. If the
recipient or printer accepts SVG, always give them that instead of the PNG.

## Usage rules

- Leave clear space of at least **half the mark's width** around the logo
- Never stretch it — always scale proportionally
- Do not recolour it or place it on a busy background; use the cream variants on
  dark backgrounds
- Minimum width of the horizontal logo in print is about **25 mm**, so the
  wordmark stays legible
- Do not use the logo as part of your own product, and do not imply that Litchi
  Dev endorses your work

## Where these files come from

The PNGs are rendered from the same SVGs used on
[litchidev.com](https://litchidev.com). If you need a different size or
background, re-render from the SVG rather than upscaling a PNG.

Missing a variant? Write to [hello@litchidev.com](mailto:hello@litchidev.com)
